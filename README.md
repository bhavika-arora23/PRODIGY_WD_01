💪 Fitness Landing Page
A responsive and interactive Fitness Landing Page built using HTML, CSS, and JavaScript. This project showcases smooth scroll-triggered navigation, a dynamic typing animation, and a modern image gallery with animated transitions.

✨ Features
✅ Fixed navigation bar with scroll-based background color change

✍️ Typing and erasing text animation for dynamic headings

🖼️ Animated gallery with images appearing one-by-one in a spotlight style

💥 Smooth "boom" animations with scale, rotation, and fade effects

📱 Responsive design for desktop and mobile devices

🔘 Join Us section with stylish call-to-action and interactive hover effects

📁 Tech Stack
HTML5

CSS3 (with animations and transitions)

Vanilla JavaScript

🎯 Purpose
This landing page is a front-end practice project focused on creating visually appealing animations, improving UI/UX, and using modern CSS/JS interactivity techniques for real-world websites
